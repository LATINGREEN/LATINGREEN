API de interoperabilidad

Para que PAID SIGIT no sea un sistema aislado: SIGIT entrega actividades y los demás sistemas de la Armada consultan datos maestros.

Contrato OpenAPI (YAML)

Autenticación

Cada sistema recibe un testigo propio, emitido por un administrador en Gestión → Sistemas externos. Se muestra una sola vez; la plataforma guarda solo su resumen SHA-256.

Authorization: Bearer sigit_…

Dos alcances: ENTREGA (enviar actividades a la bandeja de revisión) y LECTURA (consultar datos maestros). Todo sistema consulta dentro del ámbito de su unidad: la base de datos no le muestra lo de otras.

Límite: 600 peticiones por hora y por sistema. Errores con la forma {codigo, mensaje, detalles, id_correlacion}.

Entregar actividades desde SIGIT

POST /api/v1/integracion/actividades/
{"actividades": [{
  "id_externo": "RES-2026-0142",
  "tipo_jornada": "CONJUNTA",
  "descripcion": "Jornada de salud…",
  "fecha_ejecucion": "2026-09-20",
  "lugar": "Coliseo municipal",
  "municipio_dane": "52835",
  "latitud": 1.8067, "longitud": -78.7647,
  "poblacion": [{"codigo": "…", "cantidad": 40}]
}]}

Responde 202 con el resultado de cada una: RECIBIDA, ACTUALIZADA, REPETIDA o RECHAZADA (con los errores). Consulte después GET /api/v1/integracion/actividades/{id_externo}/ para saber si JACID la aprobó o por qué la rechazó.
